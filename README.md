# Тестовое задание ТОЛЬКООПТ: расчёт рекомендуемой цены

Исправленная функция `recommend_price` в `starter.py` и тесты в `test_starter.py`. Python 3.10+, только стандартная библиотека

## Запуск

```bash
python -m unittest -v
```

Тесты на `unittest` из стандартной библиотеки, ставить ничего не нужно. Проверено на Python 3.10 и 3.12

Пример из задания:

```bash
python starter.py
```

## Что исправлено

| Было | Стало |
|---|---|
| Нет ограничения ожидания источника | `asyncio.wait_for` с `timeout_s`, при тайм-ауте или исключении HOLD с текущей ценой |
| `status` не проверялся | Любой статус кроме `success` (в том числе `partial`) даёт HOLD |
| `MYSHOP` не исключался | Исключается без учёта регистра (`casefold`) |
| `delivery_days = None` ронял сравнение | Неизвестная доставка не учитывается |
| Пустой список падал на `min()` | Нет подходящих предложений: HOLD с текущей ценой, даже если она ниже `min_price` |
| `float` и `round(..., 2)` | Только `Decimal`, округление вниз до копейки (`ROUND_DOWN`) |
| `min_price` не учитывался | Рекомендация не ниже `min_price` |
| Всегда APPLY | Отклонение больше 30% в любую сторону даёт REVIEW, ровно 30% допускается |

Проверка 30% без деления: `abs(price - current) > current * 0.30`, поэтому граница считается точно

## Тесты

Обычный расчёт на данных из задания, тайм-аут, исключение источника, статус `partial`, нет подходящих предложений (свой магазин в другом регистре, неизвестная и долгая доставка), доставка ровно 6 дней, округление вниз, `min_price` как нижняя граница, ровно 30% и чуть больше 30% вверх и вниз
